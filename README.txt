Zombie Assassin Mod (Minecraft Forge 1.20.1)
=================================================

FOR PLAYERS (BEGINNERS):
------------------------
1. Install Minecraft 1.20.1 and Forge 47.2.0+.
2. Place 'zombieassasian-1.0.0.jar' into your '.minecraft/mods' directory.
3. Launch Minecraft using Forge 1.20.1.
4. Enjoy the Diamond Realm dimension, 10x10 Trap Rooms, ocean structures, cooked weapons, and multi-tools!

FOR DEVELOPERS (ADVANCED):
--------------------------
Refer to README.md for full codebase architecture, custom dimension noise settings, jigsaw structure codecs, and Gradle build instructions.

Building the mod:
  ./gradlew build

Running in dev workspace:
  ./gradlew runClient
